Why O(n) space?

The stack stores each student record in memory. As you add more students, the number of stored records grows linearly, so the total memory used increases proportionally to the number of students (n).

The operations (push/pop/peek/is_empty/size) only access or modify the top of the stack (or a count), so they run in constant time.
